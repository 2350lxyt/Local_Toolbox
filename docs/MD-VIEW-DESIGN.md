# 新工具设计方案：《MD 预览》（`md-view`）

> 状态：**已实施（v1.8.0）**。正式规格以 `docs/DESIGN.md` §17 为准（SSOT），本文档保留为设计过程记录。
> 依据：`docs/DESIGN.md` 全部红线（§1.2）、工具扩展契约（§9）、设计令牌（§3）、
> 存储键规范（§8.1）、既有先例（《文本行合并》的一键粘贴、《SQL 格式化》的超长降级、《文本对比》的附加模块）。

---

## 1. 背景与目标

聊天工具（智能体）输出的内容是 Markdown 纯文本，直接阅读时标题、代码块、表格等全部
以原始符号呈现，可读性差。本项目需要一个**以渲染为主、保留基础编辑能力**的工具：
把 Markdown 文本贴进来，立刻看到排版后的结果。

关键诉求：

1. **渲染为主**：预览区是主角，编辑区是次要的输入通道；
2. **一键粘贴渲染**：一条命令完成「读剪贴板 → 覆盖编辑区 → 立即渲染」；
3. **上下分离布局**：编辑区在上、渲染区在下，**任何宽度下都不并排**；
4. **代码块体验对齐常规 Markdown 阅读器**：围栏代码块带**语法高亮**与**一键复制**。

### 1.1 关于「已有 Markdown 编辑器实现」的事实核对

项目内**尚无**独立的 Markdown 编辑器/渲染工具。最接近的已有实现是
《文本对比》`tools/text-diff/highlight.js` 中的 **Markdown 分词着色器**
（§9.6 附加纯函数模块：围栏识别、标题/强调/行内代码着色）。

- 它是**逐行着色分词器**，只产出「着色片段」，不产出块级结构（标题层级、列表嵌套、表格），
  无法直接充当渲染器；
- 且 §9.3 明确「工具模块不得导入其它工具模块」，跨目录复用被契约禁止；
- 结论：渲染核心按 §9.6 在本工具目录内新建**附加纯函数模块** `md-core.js`；
  其「Markdown 语法特征与分词经验」作为设计参考（围栏跨行状态、自动识别规则），
  而非代码复用。本方案在「复用关系」一节逐项列出真正可复用的能力。

## 3. 与不可协商红线的符合性（逐条自检）

| 红线 | 本方案的符合方式 |

| R1 零后端 | 纯静态工具，无任何接口 |

## 5. 布局设计：上下分离，以渲染为主

```
┌──────────────────────────────────────────────┐
│ 工具条：[粘贴并渲染] [立即渲染] │ 视图▾ │ ⚙ 选项 │  ← 复用 tool.css 工具条基线
├──────────────────────────────────────────────┤
│ 编辑区（textarea.md-view__editor）            │  ← 上：高度约 32%，可折叠
│   页脚：清空 · 字符数/行数统计                 │
├────────── 拖拽分隔条（可调上下比例）────────── │
│ 渲染区（div.md-view__preview）                │  ← 下：占剩余全部高度，主角
│   页脚：块数统计 · 「复制本页为纯文本」（可选） │
└──────────────────────────────────────────────┘
```

要点：

- **只提供上下堆叠，不提供左右分栏**——即使宽屏也不引入并排视图（需求明示；同时规避
  §9.3 第 4 条「最近可滚动祖先」在两栏各自滚动的复杂度）。
- **渲染区是主角**：默认状态下编辑区高度占比小（约 32%）；分隔条可拖拽调整比例
  （编辑区最小 120px、渲染区最小 200px），比例记入会话内，不落盘。
- **「仅预览」模式**：工具条「视图」切换 `上下分离 / 仅预览`。仅预览时编辑区折叠为
  一条窄横条（显示首行摘要 + 「展开编辑」按钮），渲染区占满。两模式都是用户可配置项（R7）。
- 渲染区独立滚动：滚动容器是 `.md-view__preview` 自身（`overflow: auto`），
  不依赖页面滚动，天然满足标签工作台「最近可滚动祖先」约定。
- 编辑区复用 `assets/css/tool.css` 的 `.textarea` 基线（等宽字体、主题令牌），
  加 `md-view` 前缀修饰类做高度与折叠动画。

## 6. 核心交互流程

### 6.1 一键粘贴渲染（主路径，对标《文本行合并》「清空并粘贴」先例）

```
点击工具条「粘贴并渲染」（或 Ctrl/Cmd + Shift + V）
  1. 先读剪贴板 navigator.clipboard.readText()（复用 ctx.utils.clipboard 的降级路径）
  2. 读取成功 → 覆盖编辑区值 → 补写会话草稿 → 立即同步渲染一次（绕过 180ms 防抖）
     → **自动收起编辑区（切「仅预览」，保留摘要横条）→ 滚动到渲染区顶部**（易用性要求：
     粘贴后直接看到结果，无需再手动收起编辑区）
  3. 读取失败（无权限/空）→ 按钮内联提示「无法读取剪贴板」，编辑区内容不动
```

**顺序红线：先读后清**。任何情况下不得先清空编辑区再读剪贴板——读取失败不能破坏
用户已有输入。

### 6.2 常规输入渲染

```
编辑区 input 事件
  → 实时渲染开关开启时：180ms 防抖（与《文本行合并》同参数）→ 调 md-core 重渲染
  → 字符数 / 行数统计即时更新（复用 ctx.utils.text.countChars / countLines）
```

### 6.3 键盘（焦点守卫按 §9.3 第 2 条）

| 按键 | 行为 |
| --- | --- |
| `Ctrl/Cmd + Shift + V` | 一键粘贴渲染（document 级监听 + `root.contains(event.target)` 守卫） |
| `Ctrl/Cmd + Enter` | 立即渲染（手动模式下是唯一触发方式；实时模式下强制刷新一次） |
| `Ctrl/Cmd + Shift + C` → 改为 `Ctrl + Alt + C` | 折叠 / 展开编辑区（原定 `Ctrl+Shift+C` 与浏览器 DevTools「检查」冲突，实施时调整） |

### 6.4 渲染流程（`md-core.js` 内部）

```
原始文本
 → normalizeLineEndings（复用 utils.text，CRLF→LF）
 → 块级解析（逐行扫描：标题/围栏/列表/引用/表格/分隔线/段落）
 → 行内解析（强调/行内代码/链接/图片占位/自动链接/转义实体）
 → HTML 字符串产出（先转义后包装，见 §9 安全策略）
 → 返回 { html, stats: { chars, lines, blocks }, warnings: [] }
```

## 7. 组件与模块职责

### 7.1 `md-core.js`（附加纯函数模块，§9.6）

- **职责**：Markdown 文本 → 安全 HTML 的全部转换逻辑；统计口径计算。
- **硬性边界**：不触碰 DOM / window / localStorage；顶层只允许常量与纯函数；
  导出对象 `Object.freeze`；**任何输入都不抛异常**（宽容降级，见 §11）。
- **导出 API**（可脱离 DOM 在 Node 中验证，对标 §10.8 / §13.9 先例）：
  - `renderMarkdown(text, options) → { html, stats, warnings }`
  - `parseBlocks(lines, options) → Block[]`（块级结构，便于单测）
  - `renderInline(text, options) → string`（行内片段）
  - `countBlocks(blocks) → number`
- `options` 即 §10 的参数对象，解析行为完全由参数决定（R7：无隐藏开关）。

### 7.2 `md-view.js`（主模块，UI 编排 + 存储适配）

- **职责**：按 §9.3 解析宿主（`[data-tool-body] → #tool-body`）；构建工具条 / 编辑区 /
  分隔条 / 渲染区；绑定事件（全部经 `ctx.utils.dom.on`，解绑函数收集进清理函数）；
  防抖调度；读写实例级配置键；拼接 `md-core`。
- **禁止**：模块级可变状态；document 级监听无焦点守卫；操作其它工具 DOM；
  `import` 其它工具模块。
- DOM `id` 一律以 `ctx.instance.serial` 为前缀生成（§9.3 第 9 条，多实例
  `<label for>` / `aria-*` 不串实例）。

### 7.3 `md-view.css`（私有样式）

- 全部选择器 `.mv-*` 前缀（§9.5）；登记进 `registry.styles` **并**在独立页 `<head>`
  链接，两处同时维护（§9.5 v1.2.0 约定）。
- 颜色 / 间距 / 圆角 / 动效全部取 `tokens.css` 令牌；渲染区排版（标题字号阶梯、
  代码块底色、表格边框）用主题令牌表达，明暗双主题各校验一遍（§3.7 主题矩阵）。

## 8. 状态管理与存储键

**无模块级可变状态（R6）**。状态分三层：

| 状态 | 存放 | 生命周期 |
| --- | --- | --- |
| 编辑文本、滚动位置、分隔比例 | DOM / 内存 | 标签保活期间保留；关标签即弃（R5） |
| 会话草稿 | `sessionStorage`，键 `toolbox:md-view:session-draft[:<serial>]` | **默认写**，关闭窗口即弃（R5 例外②既有口径，界面如实告知 §8.2） |
| 用户配置 | `localStorage`，键见下表 | 持久 |

配置键（§8.1 / §9.3 第 7 条实例键规范）：

| 键 | 内容 |
| --- | --- |
| `toolbox:md-view:config` | 首个实例与独立页共用：视图模式、实时渲染、软换行、自动链接、允许原始 HTML、嵌套上限行为 |
| `toolbox:md-view:config:<序号>` | 第 2 个及以后实例各自的配置（如 `:config:2`） |

会话草稿仅存**编辑区文本**；渲染结果永不落盘（可由文本随时重算）。

## 9. 渲染策略与安全

- **先转义、后包装**：所有原文片段先过 `escapeHtml`（复用 `ctx.utils.dom`），
  再由解析器按语法位置包上白名单标签。**渲染器从不把原文直接塞进 `innerHTML`**，
  从根上消除注入面。
- **白名单标签集**（固定在 `md-core.js` 内，`Object.freeze`）：
  `h1–h6, p, br, hr, strong, em, del, code, pre, blockquote, ul, ol, li,
  table, thead, tbody, tr, th, td, a, span`。
- **链接 `href` 白名单**：仅 `http:` / `https:` / `mailto:` / `#锚点`；
  其余协议（含 `javascript:`、`data:`）整体降级为纯文本。统一
  `target="_blank" rel="noopener noreferrer"`。
- **图片不加载**（R2）：`![alt](url)` 渲染为占位 chip：`🖼 alt（URL，点击复制）`，
  不创建 `<img>`、不发请求。
- **允许原始 HTML 选项（默认关闭）**：开启后仍只放行白名单标签与安全属性
  （解析自制 HTML 子集，不引第三方 sanitizer）；关闭时 HTML 语法按字面文本显示。
  界面上对该选项附「仍不加载任何远程资源」说明（§8.5 隐私表述约定）。

### 9.1 代码块交互：语法高亮 + 一键复制

每个围栏代码块渲染为带头部栏的卡片（对齐常规 Markdown 阅读器体验）：

```
┌──────────────────────────────────────┐
│ python                        [复制] │   ← .mv-code__bar：语言标签 + 复制按钮
│ ────────────────────────────────────│
│ def hello():                        │   ← 高亮后的代码体（pre > code）
│     print("hi")                     │
└──────────────────────────────────────┘
```

**语法高亮**

- 分词能力**不新写**：把《文本对比》的 `tools/text-diff/highlight.js` **上移到
  `assets/js/utils/highlight.js`** 作为共享纯函数模块。依据：§9.6 明文
  「禁止把跨工具可复用的能力放进工具目录，必须上移 `assets/js/`」；该模块本就
  无 DOM / 无副作用 / 无依赖，上移零风险。
- 《文本对比》改为从共享路径导入（接口与导出不变，仅改 import 路径，行为零变化）；
  `md-core.js` 以相对路径 `import { highlightLine, LANGUAGES, detectLanguage }`
  引用——这是对**共享能力层**的导入（§9.4），不是对其它工具的导入（§9.3），契约允许。
- 支持语言沿用现有 11 种（SQL / JSON / XML / JS / TS / CSS / Java / Python /
  Shell / YAML / Markdown），围栏标注语言命中 `LANGUAGES` 即着色；未标注时对
  代码块首行跑 `detectLanguage`（可关，见 §10）；不支持的语言回落纯文本，不报错。
- **着色仍走「先转义后包装」**：分词器只产出 token 片段，`md-core` 据此把
  **已转义**的文本包进 `<span class="hl-<类型>">`（白名单新增 `span.hl-*` 系列类，
  样式用 `tokens.css` 主题令牌定义，明暗双主题各自校验）。不引入任何新注入面。
- **性能降级（R7 参数化）**：单代码块 > 20000 字符，或全文已触发 §11 超长模式时，
  该块不着色、回落纯文本；「语法高亮」开关（默认开）可整体关闭。

**一键复制**

- 头部栏「复制」按钮复制该代码块的**原始文本**（未转义、未着色的源码），
  复用 `ctx.utils.clipboard`（含非安全上下文降级）；成功后按钮内联变「已复制」，
  2 秒复原（对齐《SQL 格式化》复制先例）。
- 实现方式：渲染器随每块记录原始代码文本（按块索引存于实例内存，
  **不写入 DOM 属性、不落盘**，避免转义/引号问题）；预览容器上用**事件委托**
  挂一个点击监听（多实例互不影响，清理函数只解绑这一个）。
- 编辑区内容变化后重新渲染，块索引随之重建——复制永远对应当前渲染结果。

### 语法支持范围（v1）

标题 `#`–`######`、段落、**粗体**、*斜体*、~~删除线~~、`` `行内代码` ``、
围栏代码块（**带语法高亮与一键复制，见 §9.1**）、无序/有序列表（嵌套 ≤ 上限）、
任务列表 `- [ ]`、引用块（可嵌套）、表格（含对齐语法）、分隔线、
链接、图片占位、自动链接（可关）、反斜杠转义。
**不支持**：脚注、数学公式、Mermaid、HTML 块级透传（默认关闭见上）。

## 10. 参数模型（R7：所有行为都是选项）

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 视图模式 | 上下分离 | 上下分离 / 仅预览 |
| 实时渲染 | 开启 | 关闭后仅 `Ctrl/Cmd + Enter` 或「立即渲染」按钮触发 |
| 语法高亮（代码块） | 开启 | 见 §9.1；关闭后代码块为纯文本，复制按钮不受影响 |
| 代码块语言自动识别 | 开启 | 围栏未标注语言时按首行特征判定（复用 `detectLanguage`） |
| 软换行（编辑区） | 开启 | 长行折行不出横向滚动条 |
| 自动链接 | 开启 | `https://…` 裸 URL 自动成链接 |
| 允许原始 HTML | 关闭 | 见 §9 安全策略 |
| 嵌套上限 | 16 层 | 列表/引用超过上限拍平为普通段落，并在 warnings 提示 |

无「预设」体系——本工具参数少且不构成风格组合，v1 不引入预设（避免过度设计）。

## 11. 边界与异常处理

| 场景 | 行为 |
| --- | --- |
| **空内容** | 渲染区显示中性空态：`eye` 图标 + 「在上方输入或粘贴 Markdown」+「粘贴并渲染」快捷按钮（此时为主按钮）；统计归零；不产出任何块 |
| **超长文本** | 字符数 > 300000（沿用《SQL 格式化》§13 阈值先例）自动暂停实时渲染，工具条出现待办圆点 + 「立即渲染」按钮高亮；手动触发后一次性同步渲染；渲染期间按钮进入「渲染中…」禁用态 |
| **异常 / 非法 Markdown** | Markdown 语法本身宽容，解析器**永不抛错**：未闭合围栏 → 其后全部按代码块；未闭合表格 → 该行按普通段落；未配对 `**` → 字面输出；超深嵌套 → 拍平并计入 warnings；warnings 在渲染区页脚以一条可折叠提示呈现（不弹窗、不阻塞） |
| **剪贴板读取失败** | 先读后清（§6.1）：内容不变，按钮内联红字提示，2 秒后自动消失 |
| **CRLF / 尾随空白** | 复用 `utils.text.normalizeLineEndings` 统一为 LF；行尾空白不影响解析 |
| **单超长行（无空格长串）** | 渲染区 `overflow-wrap: anywhere`，不撑破布局 |
| **解析器自身异常（防御性）** | UI 层 `try/catch` 兜底：渲染区显示可读错误 + 「重试」，编辑区内容不动、不静默（§9.3「关键失败给可读提示」） |
| **多实例并存** | 一切状态按 `ctx.instance.serial` 隔离；面板内 DOM 无全局唯一 id 依赖 |

## 13. 验收要点（实施后逐条核对）

1. Node 直接导入 `md-core.js` 跑纯函数断言：空文本、仅标题、未闭合围栏、
   深嵌套、含 `<script>` 的文本（产出必须已转义）、300000+ 字符（性能）。
2. 明暗两主题下渲染区排版对照 §3.7 主题矩阵逐项核对。
3. 双实例并开：配置互不覆盖、`label for` 各归各实例。
4. `Ctrl/Cmd + Shift + V` 在并排另一工具面板聚焦时不触发（焦点守卫）。
5. 断网环境全功能可用（本就零请求，渲染一张远程图片 URL 验证不发起加载——
   DevTools Network 面板零记录）。
6. 空态 / 超长 / 非法语法三类边界按 §11 逐条演练。
7. 代码块（§9.1）：①含 `<script>` 的代码块复制结果与原文逐字符一致；②11 种语言
   各贴一段最小样本核对高亮，明暗双主题各过一遍；③未标注语言的代码块自动识别
   正确、不支持语言回落纯文本；④单块 > 20000 字符不着色但复制可用；⑤关闭
   「语法高亮」开关后其余行为不变；⑥双实例并开时各复制各的块（事件委托按
   `ctx.root` 作用域绑定）。
8. 《文本对比》回归：highlight.js 上移后，原工具高亮、自动识别、彩虹括号等
   行为与上移前逐项一致（零回归方可合并）。

# 本地工具箱（Local Toolbox）

一个**全部计算在浏览器客户端完成**的静态工具集网页。页面不依赖任何后端服务，
不上传任何数据，也不请求任何第三方资源（无 CDN、无外链字体、无埋点），
在节约流量的同时严格保障隐私安全。

> **开始改动前请先读 [`docs/DESIGN.md`](./docs/DESIGN.md)。**
> 该文档是项目的设计基准（Single Source of Truth），记录了七条不可协商的红线、设计令牌、
> 工具扩展契约与《文本行合并》的完整功能规格。**若需改变既定设计，必须先更新该文档并写明理由，再改动代码。**

## 核心特性

- **左列表右标签工作台**：点击左侧工具项在**当前页面内**打开该工具的标签页，不再整页跳转；
  已打开的标签**常驻不销毁**，来回切换时输入内容、选区与滚动位置全部保留，多工具并行无需再开多个网页。
- **同一工具可重复打开多个独立实例**：每次点击左侧工具项都会新开一个标签（例如同时开 3 个《SQL 格式化》处理不同脚本），
  各实例独立加载、独立运行、互不干扰；重复打开时显示名自动追加数字后缀（「文本行合并 (2)」「(3)」…），原标签名称与内容不变。
- **标签重命名**：双击标签标题，或用标签上的「⋯」菜单 / 右键菜单 / `F2`，即可就地改名并**实时生效**（允许重名，最多 40 字符）。
- **标签栏**：位于内容区上方，展示名称与活动状态，支持任意切换与两段式确认关闭；标签可**拖拽排序**，
  也可**拖到画面右侧并排显示**（左右两栏各带独立标签栏与滚动区，右栏清空后自动退回单栏）。
- **布局记忆**：已打开的标签组合、名称、顺序、分栏与激活项会被记住（刷新后恢复）；
  但**输入内容与所有工具一样永不落盘**。
- **动态扩展**：新增工具只需在注册表中登记一条记录，列表与首页总览自动更新。
- **列表可收起**：左侧列表可手动收起为窄图标条，释放内容区空间；收起状态会被记住，
  鼠标悬停图标时显示工具名称。
- **工具解耦**：每个工具拥有**独立入口页面**与**独立处理模块**，工具之间不共享状态、互不干扰；
  标签工作台只是同一模块的另一个宿主（一个标签一个面板、各自独立实例）；
  仅主题、图标、剪贴板、文本处理等公共能力由共享层提供。
- **明暗主题**：默认跟随系统深色/浅色模式，并提供手动切换按钮（跟随系统 → 浅色 → 深色）。
- **键盘可达**：标签支持 `←` / `→` 切换、`Delete` 两段式关闭，并提供「⋯」菜单（含并排操作）作为拖拽的键盘等价路径。
- **零构建**：原生 HTML + CSS + ES Module，无需打包与编译，静态托管即可运行。

## 标签工作台的使用

- **打开**：点击左侧工具项或首页工具卡片，即在本页**新建一个标签**；同一个工具想开几个就点几次，
  第 2 个及以后会自动命名为「工具名 (2)」「工具名 (3)」…（回到已有标签靠标签栏切换，不提供「只激活」的点击行为）。
- **切换 / 关闭**：点击标签切换；关闭按钮**首次点击进入待确认态**（3 秒内再次点击才真正关闭，`Esc` 取消）。
- **重命名**：双击标签标题、用标签「⋯」菜单或右键菜单里的「重命名」、或聚焦标签后按 `F2` → 就地改名（`Enter` 提交、`Esc` 取消、
  失焦提交）；名称可包含任意字符、允许重名，最长 40 字符。
- **排序**：按住标签左右拖动，出现强调色竖条即为插入位置。
- **并排**：把标签拖到画面右侧的投放区，即与主栏并排显示；把并排栏的标签拖回主栏标签栏即合并，
  并排栏清空后自动退回单栏。标签栏上的「⋯」菜单（也可右键或 `Shift + F10` 唤起）提供同样的操作。
- **键盘**：`←` / `→` 在标签间移动并把焦点移到该标签，`Home` / `End` 跳到首/末，`F2` 重命名，`Delete` 两段式关闭。
- **上限**：同时最多打开 8 个标签；达到上限时会提示先关闭部分标签。
- **数据边界**：标签组合、显示名与分栏会被记住（`localStorage` 键 `toolbox:tabs`），但**输入内容不会**——
  所有工具都不持久化你粘贴的文本，关闭标签即丢弃该标签内的输入。

## 内置工具

### 文本行合并（`text-line-merge`）

把多行文本按指定分隔符合并为一行。全部计算在本机完成。

**参数（所有能力都是可配置选项）**

| 选项 | 说明 |
| --- | --- |
| 分隔符 | 任意字符串，留空表示直接拼接 |
| 每行前缀 / 后缀 | 加在每行开头与结尾，例如单引号用于生成 SQL 的 `IN` 列表 |
| 去除每行首尾空白 | 合并前逐行 trim |
| 忽略空行 | 丢弃 trim 后为空的行走 |
| 启用转义 | 对**行内容**（不含前后缀）转义指定字符 |

转义配置：转义字符（默认 `'`）+ 转义方式（双写 `'` → `''`，或反斜杠 `'` → `\'`）。

合并顺序固定为：`拆分行 → 去除首尾空白（可选）→ 忽略空行（可选）→ 行内容转义（可选）→ 套前后缀 → 用分隔符连接`。

**内置预设**（预设只是一组参数取值，不含任何专属逻辑）

| 预设 | 参数 |
| --- | --- |
| 英文逗号合并（默认） | 分隔符 `,`，无前后缀 |
| 英文逗号 + 空格 | 分隔符 `, ` |
| SQL 列表 | 分隔符 `,`，前后缀 `'`，并默认勾选去首尾空白、忽略空行、单引号转义 |
| 空格合并 | 分隔符 ` ` |
| 竖线分隔 | 分隔符 ` \| ` |
| 直接拼接 | 无分隔符 |

**自定义预设与跨浏览器迁移**

- 「另存为」把当前参数组合保存为该名称的预设；同名会覆盖已有自定义预设，与内置预设重名会被拒绝。
- 「删除」为两段式确认（再次点击确认），仅自定义预设可删除。
- 「导出」下载全部自定义预设为带版本号的 JSON 文件；「复制 JSON」复制同样内容到剪贴板。
- 「导入」支持选择 `.json` 文件或直接粘贴 JSON，全程在本机解析、不上传。同名预设以导入内容为准覆盖，完成后会明确提示新增／覆盖／跳过的条数；非法文件给出可读错误且不写入任何数据。导入只恢复预设，**不会改动你当前正在编辑的参数**。

**数据边界（重要）**

自定义预设保存在浏览器 `localStorage`，因此：

- 刷新页面、关闭再打开浏览器后依然保留；
- 但在**无痕模式**、**清除浏览器数据**、**更换浏览器或设备**后为空，且不会跨设备同步；
- 需要迁移或备份时请使用「导出 / 导入」。

**本地存储键名**

| 键 | 内容 |
| --- | --- |
| `toolbox:text-line-merge:presets` | 自定义预设列表（**跨实例共享**） |
| `toolbox:text-line-merge:config` | 该工具**首个实例**与独立页共用的上次参数与预设选择 |
| `toolbox:text-line-merge:config:<序号>` | 该工具**第 2 个及以后实例**各自的上次参数与预设选择（如 `:config:2`） |

> 实例序号在标签关闭后会被回收复用，因此实例键数量有界（最多与同时打开的标签数相当），
> 且重开同一位置的标签会恢复「上次的参数」。

输入文本本身**不做任何持久化**。

### SQL 格式化（`sql-format`）

面向 **Oracle / PostgreSQL** 的 SQL 代码编辑器：格式化、语法高亮、关键词搜索、
选中相同文本全部高亮，并含行号、括号匹配与 Tab / 自动缩进。全部计算在本机完成。

**核心能力**

| 能力 | 说明 |
| --- | --- |
| 格式化 | 主按钮或 `Ctrl/Cmd + Enter`；按下方参数重排 SQL 的折行、缩进与大小写 |
| 语法高亮 | 保留字 / 数据类型 / 内置函数 / 字符串 / 数字 / 注释 / 运算符 / 双引号标识符 / 绑定变量分别着色 |
| 关键词搜索 | `Ctrl/Cmd + F` 展开搜索条，支持区分大小写、全词匹配，上一个 / 下一个循环定位并显示命中计数 |
| 选中相同文本高亮 | 选中非空、不含换行且长度 ≤ 64 字符的文本时，自动高亮全文所有相同出现处 |
| 编辑器增强 | 行号栏（随软换行自适应）、括号匹配高亮（未配对转错误态）、`Tab` / `Shift + Tab` 缩进、`Enter` 自动缩进 |

**格式化参数（所有行为都是可配置选项）**

| 选项 | 说明 |
| --- | --- |
| 方言 | Oracle / PostgreSQL，决定保留字与内置函数识别集合 |
| 缩进 | 空格（2 / 4 / 8）或 Tab |
| 大小写 | 保留字、内置函数名、标识符各自独立设为大写 / 小写 / 保持 |
| 逗号位置 | 行尾或行首 |
| 子句换行 | `SELECT` / `FROM` / `WHERE` 等主子句是否各起一行 |
| 选择列表换行 | 逐列换行 / 自动（超出软性行宽才换行）/ 不换行 |
| 行宽 | 软性上限（0 表示不限制） |
| 括号内换行 | 函数参数、`IN` 列表等是否换行并缩进 |
| `AND` / `OR` 缩进 | 子句内逻辑连接词是否换行并缩进 |
| 空行 | 保留原有空行，或压缩为单行 |

**内置预设**：标准（默认）、紧凑风格、展开风格、前导逗号、关键字小写、四空格缩进、
Tab 缩进、PostgreSQL 惯例、Oracle 惯例。预设只是一组参数取值，不含专属逻辑。

**自定义预设与跨浏览器迁移**：与《文本行合并》一致 —— 「另存为」保存当前参数组合，
与内置预设重名会被拒绝、与自定义预设同名则覆盖；「删除」为两段式确认；
「导出 / 复制 JSON / 导入」全程在本机完成（`Blob` / `FileReader`），同名以导入内容为准覆盖，
非法内容整体拒绝并给出可读错误。导入只恢复预设，**不会改动你当前正在编辑的 SQL 或当前参数**。

**数据边界（重要）**

- 自定义预设保存在浏览器 `localStorage`，刷新与重开浏览器后保留；
- **无痕模式、清除浏览器数据、更换浏览器或设备后为空**，且不跨设备同步；需要迁移请用「导出 / 导入」；
- **编辑中的 SQL 文本不做任何持久化**，只存在于内存与当前页面中。

**本地存储键名**

| 键 | 内容 |
| --- | --- |
| `toolbox:sql-format:presets` | 自定义预设列表（**跨实例共享**） |
| `toolbox:sql-format:config` | 该工具**首个实例**与独立页共用的上次参数与预设选择 |
| `toolbox:sql-format:config:<序号>` | 该工具**第 2 个及以后实例**各自的上次参数与预设选择（如 `:config:2`） |

**超大输入**：文本超过 300000 字符时会自动关闭语法高亮与搜索高亮，仅保留纯文本编辑，
以保证输入流畅。

## 本地预览

项目是纯静态站点，用任意静态服务器打开即可（**不能直接双击 HTML**，
因为 ES Module 需要 HTTP 环境）：

```bash
npm run dev          # 等价于 npx --yes serve -l 5173 .
# 或
python -m http.server 5173
```

然后访问 <http://localhost:5173/>。

## 新增一个工具（三步）

1. **建目录与页面**：复制 `tools/text-line-merge/` 为 `tools/<工具 id>/`，
   修改其中的 `index.html`（记得保留 `<div id="shell-root">`、`<main class="workspace" id="workspace">`、
   `body[data-tool="<工具 id>"]` 与 `../../assets/js/tool-redirect.js`，并调整 `../../` 相对路径）。
   该页是有脚本时的重定向入口（跳到 `index.html#/<工具 id>`），也是无脚本时的兜底页面。
2. **写处理模块**：在同目录创建 `<工具 id>.js`，导出 `init(ctx)`：

   ```js
   export function init(ctx) {
     const { root, tool, utils, icons } = ctx;
     // root：独立页为 main.workspace；标签工作台模式下为标签面板容器
     const host = root.querySelector("[data-tool-body]") || root.querySelector("#tool-body");
     // 在此渲染界面、绑定事件；不要直接操作其它工具的 DOM
     return () => {}; // 返回清理函数：关闭标签时调用，须注销全部监听与定时器
   }
   ```

   **标签工作台下的三条硬性要求**（详见 `docs/DESIGN.md` §9.3）：宿主必须按 `[data-tool-body] → #tool-body`
   的顺序解析；`document` 级快捷键必须加「焦点在自身面板内」守卫；需要滚动定位时使用「最近的可滚动祖先容器」，
   不要假定 `window` 是滚动容器。

3. **注册**：在 `assets/js/registry.js` 的 `TOOLS` 数组中追加一条记录：

   ```js
   {
     id: '<工具 id>',                     // 与 body[data-tool] 一致
     name: '工具名称',
     icon: 'merge',                       // icons.js 中的图标名
     description: '一句话说明',
     path: 'tools/<工具 id>/index.html',  // 站点根相对路径
     entry: 'tools/<工具 id>/<工具 id>.js',
     styles: ['tools/<工具 id>/<工具 id>.css'], // 有私有 CSS 时必须登记（标签页按需注入）
     status: 'planned'                    // ready | planned
   }
   ```

外壳代码无需改动，左侧列表与首页总览会自动出现该工具。

### 路径约定（重要）

`registry.js` 中的 `path` / `entry` 一律使用**站点根相对路径**（不带前导 `/`），
由 `shell.js` 通过 `import.meta.url` 解析为绝对地址。这样做可以同时兼容
CloudBase 根路径部署与 GitHub Pages 子路径（`/仓库名/`）部署，
请勿在代码中硬编码以 `/` 开头的根路径。

## 部署

### 腾讯云 CloudBase 静态托管（优先）

1. 在 CloudBase 控制台创建环境，进入「静态网站托管」。
2. 上传仓库根目录下的全部静态文件（`index.html`、`assets/`、`tools/` 等），
   保持目录结构不变；也可以使用 CloudBase CLI 上传。
3. 无需任何构建命令、环境变量或重写规则 —— 本项目无构建步骤，也没有前端路由：
   标签工作台只使用 `#/<工具 id>` 形式的 hash 直链，静态托管与子路径部署都无需额外配置。

### GitHub Pages（兼容）

1. 推送仓库到 GitHub，在仓库 Settings → Pages 中选择分支与目录（`/root`）。
2. `.nojekyll` 已放在仓库根目录，用于跳过 Jekyll 处理。
3. 由于所有资源路径都是相对解析的，部署在 `https://<用户>.github.io/<仓库名>/`
   子路径下同样可以正常加载。

## Git 协作约定

本项目使用 Git 进行版本管理，但**仅在明确要求时才提交**：

- 严禁自行执行 `git commit` / `git push`；只有用户明确提出提交要求时才可以提交。
- 提交信息使用**中文**，并遵循 Conventional Commits 规范，例如：

  ```
  feat(文本行合并): 新增分隔符与空行处理选项
  fix(外壳): 修复侧边栏收起后状态未持久化的问题
  docs: 补充新增工具的三步指南
  chore: 初始化项目结构
  ```

- 必要时按功能类型分批提交（例如框架搭建、工具实现、文档更新分别提交），保持历史整洁。

### 提交前的隐私红线

本项目用于公开开源仓库，提交前必须确认**不含**任何以下内容：

- 密钥、令牌、口令、私钥、`.env` 文件、连接字符串；
- 个人身份信息（真实姓名、`@` 邮箱地址、手机号）；
- 含有用户名的绝对路径（如 `C:\Users\<用户名>\…`）、机器名、内部域名；
- 编辑器/智能体本地工作区目录（`.codebuddy/`）与临时脚本、本地导出文件。

建议提交前执行：

```bash
git status                          # 确认待提交清单
git diff --cached | grep -iE "password|secret|token|api[_-]?key|@[a-z0-9.-]+\.[a-z]{2,}"
```

另请注意：Git 会把提交者的姓名与邮箱写入提交记录，公开仓库中该信息对所有人可见。
如需隐藏，可在提交时使用 GitHub 提供的 noreply 邮箱。
